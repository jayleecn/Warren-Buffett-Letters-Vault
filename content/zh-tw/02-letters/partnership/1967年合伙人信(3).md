# 巴菲特合夥人信 — 1967年

巴菲特合夥基金有限公司
基威特大廈610號
內布拉斯加州奧馬哈 68131
電話 042-4110

[[沃伦·巴菲特|沃倫·E·巴菲特]]，普通合夥人
威廉·斯科特
約翰·M·哈丁

1967年11月1日

致我的合夥人：

隨信附上：

1. 兩份1968年承諾書，一份由你保留，一份寄回給我們。你可以在12月31日之前隨時修改承諾書，所以請儘早寄回，如需更改，來信或致電告知即可。承諾書在12月31日絕對定稿——此規則不容例外，因為屆時我會將其移交給畢馬威會計師事務所。

2. 一封稅務信函，提供我目前對1967年已實現投資交易的年終預估。今年我們處置了一些重要持倉，在此過程中實現了約2,400萬美元的收益。因此，在寄回承諾書之前，請務必仔細審視你的稅務狀況，以免明年四月讓國稅局感到失望。如需幫助，約翰·哈丁很樂意幫你粗略估算稅務需求。

3. 一份2月2日寄給你的信函副本，其中包含稅務信中解釋的計算所需數據。過去我們總讓你翻箱倒櫃找這封信——一位合夥人提出了絕妙的建議，讓我們此時隨信附上一份副本。

4. 一份"基本規則"副本，其中第四條和第五條已完全修改，以反映我10月8日信中解釋的新條件。如果第四條中設定的目標即使實現也不能令你滿意（而且那只是目標，不是承諾），你最好在年底撤資。在目前的條件下，部分合夥人很可能有更好的資金去處，如果確實如此，做出調整是合理的。

任何撤資將在1月5日之前支付。你可以提取100美元到全部權益之間的任何金額。同樣，追加投資金額不限，應在1月10日之前到賬。如果追加資金在11月到賬，將被視為預付款，到年底前按6%計息。12月到賬的追加資金不計利息。

在我寫這封信時，[[道琼斯工业指数]]大約在880點，今年以來的整體回報約為正15%。我們的業績約為正27%，折算為有限合夥人約正22%（扣除每月提款前）。這不涉及我們對年末[[控制类投资]]估值相對1966年底的任何變化。在12月22日確認你承諾書狀態的信中，我將告知你我們對[[多元零售公司]]和[[伯克希尔·哈撒韦]]的估值，並附上與該估值相關的財務資料。這一調整可能會為我們今年的業績增加少量收益。

在解讀我們今年剩餘時間乃至明年的業績時，你應當瞭解：我們不僅有約2,000萬美元投資於[[控制类投资|控制類公司]]，還有超過1,600萬美元的短期國債。目前合計超過3,600萬美元，這些資金顯然不會參與股市可能出現的任何上漲。這並不反映我對市場的判斷；僅僅意味著我找不到任何明顯有利可圖且安全的投資去處（從長期[[内在价值]]角度看，而非短期報價角度）。我們通常在每年初都有幾個即將孵化的投資機會；但目前巢穴幾乎是空的。這種情況可能會很快改變，也可能持續一段時間。提及此事只是為了在近期股市走強的情況下，適度調低你對我們業績的預期。

此致敬意，

沃倫·E·巴菲特

WEB/eh
