# 巴菲特聯合有限合夥公司——有限合夥證書

**有限合夥證書**

以下籤署人特此證明，各方於本日訂立有限合夥關係，具體條款如下：

## 一

合夥企業名稱為：**巴菲特聯合有限合夥公司**（BUFFETT ASSOCIATES, LTD.）

## 二

本合夥企業經營業務的性質為：以合夥企業賬戶買賣股票、債券及其他證券、大宗商品及其他投資品。

## 三

主要營業地點設於內布拉斯加州道格拉斯縣奧馬哈市。

## 四

普通合夥人為：

[[沃伦·巴菲特|沃倫·E·巴菲特]]
內布拉斯加州，奧馬哈

有限合夥人為：

小查爾斯·E·彼得森
內布拉斯加州，奧馬哈

伊麗莎白·B·彼得森
內布拉斯加州，奧馬哈

多麗絲·B·伍德
內布拉斯加州，奧馬哈

杜魯門·S·伍德
內布拉斯加州，奧馬哈

小丹尼爾·J·莫寧
內布拉斯加州，奧馬哈

威廉·H·湯普森
內布拉斯加州，奧馬哈

愛麗絲·R·巴菲特
內布拉斯加州，奧馬哈

以上人員以下統稱為有限合夥人。

## 五

本合夥企業的存續期限自1956年5月1日起至1976年4月30日止，除非依據合夥協議的規定或內布拉斯加州法律的規定提前終止。

## 六

各有限合夥人出資的現金金額如下：

| 有限合夥人 | 出資額 |
|-----------|--------|
| 小查爾斯·E·彼得森 | $5,000.00 |
| 伊麗莎白·B·彼得森 | $25,000.00 |
| 多麗絲·B·伍德 | $5,000.00 |
| 杜魯門·S·伍德 | $5,000.00 |
| 小丹尼爾·J·莫寧 | $5,000.00 |
| 威廉·H·湯普森 | $25,000.00 |
| 愛麗絲·R·巴菲特 | $35,000.00 |

## 七

各有限合夥人未約定追加出資義務。

## 八

在合夥企業終止日屆滿或有限合夥人退夥之前，各方未約定返還有限合夥人出資的時間。

## 九

各有限合夥人因其出資而應獲得的利潤分成或其他收入補償方式如下：每位有限合夥人應按年利率4%獲得利息，利息按其截至上一年度12月31日的資本賬戶餘額計算，該餘額以合夥企業就該年度經營活動申報的聯邦所得稅申報表所載數據為準，上述利息支付計入合夥企業經營費用。為替代截至1956年12月31日期間的單獨利息計算，每位有限合夥人應獲得其原始出資額2%的支付，該支付計入該期間合夥企業經營費用。此外，各有限合夥人應按其姓名對應的以下比例，分享合夥企業的整體淨利潤，即合夥企業自成立之日起至任何給定時點的淨利潤：

| 有限合夥人 | 利潤分配比例 |
|-----------|------------|
| 小查爾斯·E·彼得森 | 1/42 |
| 伊麗莎白·B·彼得森 | 5/42 |
| 多麗絲·B·伍德 | 1/42 |
| 杜魯門·S·伍德 | 1/42 |
| 小丹尼爾·J·莫寧 | 1/42 |
| 威廉·H·湯普森 | 5/42 |
| 愛麗絲·R·巴菲特 | 7/42 |

## 十

有限合夥人無權以受讓人替代其出資人地位。

## 十一

各合夥人無權接納新增有限合夥人。

## 十二

各有限合夥人之間不存在優先權。

## 十三

普通合夥人死亡、退休或喪失行為能力時，其餘合夥人無權繼續經營合夥企業業務。

## 十四

有限合夥人無權要求並接收現金以外的財產作為其出資的返還。
